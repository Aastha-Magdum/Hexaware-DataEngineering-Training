# Cloud Computing

Cloud computing is a technology that provides computing resources such as servers, storage, databases, networking, and software over the internet. Instead of purchasing and maintaining physical hardware, users can access these resources whenever needed and pay only for what they use.

Cloud computing allows organizations and individuals to store data, run applications, and perform various computing tasks without investing heavily in infrastructure.

## How Cloud Computing Works

Cloud providers maintain large data centers that contain servers, storage devices, and networking equipment. Users connect to these resources through the internet and use them according to their requirements.

### Common Uses

- Website hosting
- Data storage
- Application development
- Database management
- Data analytics
- Backup and recovery

# What is Hosting in Azure?

Hosting in Azure refers to deploying and running websites, applications, databases, or services on Azure's cloud infrastructure.

Instead of keeping an application on a personal computer or local server, it is deployed to Azure servers where users can access it through the internet.

## Example

A developer creates a web application and uploads it to Azure. Azure stores the application on its servers and makes it available online for users worldwide.

---

## Types of Hosting in Azure

### 1. Azure Virtual Machines

Provides complete control over a virtual server.

**Suitable for:**

- Custom applications
- Legacy software
- Full server administration

### 2. Azure App Service

A managed platform for hosting web applications and APIs.

**Suitable for:**

- Web applications
- REST APIs
- Mobile backends

### 3. Azure Kubernetes Service (AKS)

Used to host containerized applications.

**Suitable for:**

- Microservices
- Large-scale applications

### 4. Azure Storage Hosting

Used to host static content.

**Suitable for:**

- Static websites
- Images
- Videos
- Documents

# IaaS (Infrastructure as a Service)

Infrastructure as a Service provides virtualized computing resources over the internet.

The cloud provider manages:

- Physical servers
- Networking
- Storage
- Data centers

The customer manages:

- Operating systems
- Applications
- Data

## Example

Azure Virtual Machines

A company creates a virtual machine, installs Windows or Linux, and manages all software on that machine.

### Advantages

- High flexibility
- Full control
- Easy scaling
- Reduced hardware costs

---

# PaaS (Platform as a Service)

Platform as a Service provides a ready-to-use environment for developing and deploying applications.

The cloud provider manages:

- Hardware
- Operating systems
- Networking
- Runtime environments

The customer manages:

- Application code
- Data

## Example

Azure App Service

Developers deploy applications directly without managing servers.

### Advantages

- Faster development
- Reduced maintenance
- Automatic updates
- Simplified deployment

---

# SaaS (Software as a Service)

Software as a Service provides complete software applications through the internet.

The cloud provider manages everything, including infrastructure, software, updates, and security.

Users simply access and use the application.

## Examples

- Microsoft 365
- Gmail
- Google Docs
- Zoom

### Advantages

- No installation required
- Accessible from anywhere
- Automatic updates
- Minimal maintenance

---

# Difference Between IaaS, PaaS, and SaaS

| Feature            | IaaS                   | PaaS                  | SaaS          |
| ------------------ | ---------------------- | --------------------- | ------------- |
| User Manages       | OS, Applications, Data | Applications, Data    | Only Usage    |
| Provider Manages   | Hardware, Network      | Hardware, Network, OS | Everything    |
| Flexibility        | High                   | Medium                | Low           |
| Maintenance Effort | High                   | Medium                | Very Low      |
| Example            | Azure Virtual Machines | Azure App Service     | Microsoft 365 |

---

# Easy Summary

## IaaS

Rent infrastructure such as servers and storage.

**Example:** Azure Virtual Machines

## PaaS

Rent a platform to develop and deploy applications.

**Example:** Azure App Service

## SaaS

Use ready-made software through the internet.

**Example:** Microsoft 365
