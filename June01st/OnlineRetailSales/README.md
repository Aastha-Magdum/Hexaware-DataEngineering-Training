# Online Retail Sales Analytics Database

## Database Design

For this project, I created a database for an online retail company. The purpose of this database is to store customer details, product information, order records, payment details, and delivery information in an organized manner.

## Tables Used

The database contains six tables:

- Customers
- Products
- Orders
- Order Items
- Payments
- Deliveries

## Table Relationships

- Customers and Orders are connected through Customer ID.
- Orders and Order Items are connected through Order ID.
- Products and Order Items are connected through Product ID.
- Payments are linked with Orders through Order ID.
- Deliveries are linked with Orders through Order ID.

## Key Insights from Reports

- Revenue reports show total income generated from successful payments.
- City-wise reports help identify high-performing locations.
- Customer reports identify frequent buyers.
- Product reports identify best-selling products.
- Payment reports help track failed and pending payments.
- Delivery reports help monitor delivery performance.

## Conclusion

This project demonstrates how SQL can be used to store, manage, and analyze retail business data effectively.
